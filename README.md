# Albion Craft Master v0.4

Interface reorganizada e ampliada.

## Novidades
- Busca de itens como função principal.
- Catálogo real do ao-bin-dumps, com nomes/localização quando disponíveis.
- Página individual de mercado.
- Preço atual por cidade/qualidade.
- Histórico de preços.
- Comparação entre cidades.
- Favoritos.
- Histórico de cálculos.
- Scanner de crafting.
- Calculadora de crafting.
- Módulo inicial de refinamento.
- Interface mobile/PC com estética preto/cinza/verde.
- Sem capital/meta no painel.
- Sem Discord.

## Fontes
AODP Américas/West: https://west.albion-online-data.com
Catálogo: https://github.com/ao-data/ao-bin-dumps
Receitas: https://github.com/vkorne-web/albion-market

## Limitação importante
AODP é uma fonte comunitária. A ferramenta mostra idade dos dados e não deve tratar margem calculada como lucro garantido. Consulte/abra o mercado no jogo para confirmar oportunidades relevantes.

## Uso
Abra index.html. Para instalar como PWA no Android, a pasta precisa ser servida por HTTPS. O modo recomendado é hospedá-la como site estático privado/obscuro ou usar um servidor local.
