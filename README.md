# Albion Craft Master v1.3

Painel unificado: Buscar + Mercado + Craft em uma única aba. Scanner fica por último.

A aplicação está preparada para HTTPS/PWA: inclui service worker, manifest e arquivos de configuração para hospedagem estática.

## Dados
- Albion Online Data Project — Americas/West
- Catálogo de itens ao-data/ao-bin-dumps
- Banco de receitas remoto usado pelo aplicativo

## Importante
Para consultas externas funcionarem de forma consistente, abra a aplicação por HTTPS (hospedagem web) ou localhost. Abrir pelo `content://` do gerenciador de arquivos pode bloquear fetches externos do navegador.
